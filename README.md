# Velazquez Lab

11 free tools I actually needed. No bloat, no trackers, all free and open.

**Live site: https://velazquez-lab.pages.dev**

Built with Muse + Antigravity. Muse plans, checks, and ships. Antigravity builds on the PC. Cesar tells them both what to make.

## The tools

- **Free Video Compressor** (v8.1) — paste a video, get a smaller MP4. 100% in-browser, nothing uploads.
- **AppForge** — see the hub for details.
- **Clean Apps** — 198 verified iPhone apps with no ads and no in-app purchases.
- **app-horde** — a clean index of sideloadable iOS apps.
- **droidhorde** — multi-source APK index for Android.
- **Deadlock Build Guide** — builds for all 44 Deadlock heroes.
- **LocalDrop** (v21.3) — send anything to devices near you, peer-to-peer.
- **Lock Launcher** (latest release v2.29) — an app dock on your Android lock screen.
- **TV Clean Home** (v1.2.2) — a lightweight launcher and debloater for Chromecast and Fire TV.
- **Color Block** (v8) — an ad-free block puzzle game.
- **MarketTrack** — free in-browser calorie counter, 267 foods across H-E-B, Walmart, Sam's Club and Joe V's.

This repo holds the hub site itself (`index.html`, `badges.json`, `previews/`, `downloads/`). Each tool lives in its own repo — see the hub for links.
