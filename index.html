How I built it

No CS degree, no boilerplate marathons. A problem, a plain-words description, and an agent that writes the code while I steer.

Muse plans, checks, and ships. Antigravity builds on the PC. Cesar tells them both what to make.

  1. step 01 — the itch

    Hit a wall in my own workflow

    A compressor that stamps a watermark. An app store where “free” means ads plus IAP. Repos LiveContainer can't search. Every tool here started as my own problem first.

  2. step 02 — the prompt

    Describe it in plain words

    I tell Muse and Antigravity what I want like I'd tell a person: what it does, what it must never do (track, watermark, phone home), and how it should feel. Muse drafts the plan and the code; Antigravity builds on the PC.

  3. step 03 — the loop

    Test on real devices, iterate fast

    I run everything on my own phone and PC, break it, and feed the failures straight back. Most tools went from idea to usable in a single sitting.

  4. step 04 — ship it

    Push to Codeberg, deploy free

    Everything lands on Codeberg under crtGhoul and deploys to Cloudflare Pages — $0 hosting, $0 trackers, free for everyone.

Frequently asked questions

The honest answers, up front.

Is everything really free — what's the catch?

Yes — every tool on this page is free: no accounts, no paywalls, no trackers, no ads. The tools stay free either way.

Is my video really private in the compressor?

Yes. The compressor runs ffmpeg.wasm entirely in your browser — your file is processed on your own device and never uploaded anywhere. There is no server receiving it; close the tab and nothing remains.

Is sideloading safe?

app-horde shows a VirusTotal verdict for every build it lists, so you can see scan results before you install anything. These are still unofficial builds from third-party sources, though — check the verdicts and do your own research before sideloading.

Why was this built with Muse + Antigravity?

I'm one builder working with an AI agent instead of a team: I describe each tool in plain words, Muse and Antigravity write the code, and I test and steer. Most of these tools went from idea to shipped in about a week — that's the whole model behind this page.

What if I run into an error or need help with a tool?

Every tool is open source! If you encounter an unexpected issue, bug, or edge case on any tool, you can open an issue on the project's repository on Codeberg or GitHub. All setup scripts and source code are public and audited for safe execution.

How does TV Clean Home stay safe on Fire TV Stick & Chromecast without breaking system settings?

On Android TV and Amazon Fire OS, disabling the stock system launcher completely can break core display services and lock you out of Settings. TV Clean Home solves this by using a high-speed accessibility watchdog that intelligently intercepts remote Home button presses, while explicitly whitelisting native Fire TV Settings, Wi-Fi configuration, Quick Settings HUD, and Google Free TV channels. This guarantees zero black screens, zero boot loops, and full control over your TV.
