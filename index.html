How I built it

No CS degree, no boilerplate marathons. A problem, a plain-words description, and an agent that writes the code while I steer.

  1. step 01 — the itch

    Hit a wall in my own workflow

    A compressor that stamps a watermark. An app store where “free” means ads plus IAP. Repos LiveContainer can't search. Every tool here started as my own problem first.

  2. step 02 — the prompt

    Describe it in plain words

    I tell Muse what I want like I'd tell a person: what it does, what it must never do (track, watermark, phone home), and how it should feel. Muse drafts the plan and the code.

  3. step 03 — the loop

    Test on real devices, iterate fast

    I run everything on my own phone and PC, break it, and feed the failures straight back. Most tools went from idea to usable in a single sitting.

  4. step 04 — ship it

    Push to GitHub, deploy free

    Everything lands on GitHub under crtGhoul and deploys to GitHub Pages or Cloudflare — $0 hosting, $0 trackers, free for everyone.
